## 🛠 Featured Project — [PeerDrop](https://github.com/Maruf-Hasan1789/peerdrop)

*Open-source, cross-platform peer-to-peer file transfer for local networks — no cloud, no servers.*

- **Discovery:** zero-configuration LAN peer discovery via **mDNS / Zeroconf**
- **Protocol:** custom TCP transfer protocol with **length-prefixed framing**, **Protobuf** control messages and **SHA-256** integrity checks
- **Concurrency:** parallel peer transfers using **goroutines, channels and context cancellation**
- **Stack:** Go · Wails · TCP · Protobuf · mDNS · JavaScript — runs on Linux, Windows and macOS
